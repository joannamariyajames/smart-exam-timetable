Smart Exam Timetable Generator

Each subject is a vertex. Two subjects are joined by an edge if some student takes both. Colouring the graph so that no edge joins two same-coloured vertices gives every subject a time slot with zero clashes.

    How it works

    1. Sets. Each subject S has a set of students E(S).
    2. Intersection. Subjects A and B clash iff E(A) ∩ E(B) ≠ ∅. The union E(A) ∪ E(B) is the number of students affected by the pair, and E(A) − E(B) the students unaffected by B.
    3. Graph. G = (V, E) with V the subjects and an edge for every clashing pair, stored as an adjacency matrix and adjacency list.
    4. Colouring. A proper colouring assigns each vertex a colour so adjacent vertices differ. Colour = time slot, so the number of colours used = the number of slots needed. The minimum possible is the chromatic number χ(G); the largest clique gives a lower bound ω(G) ≤ χ(G).
